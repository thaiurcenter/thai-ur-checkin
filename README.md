## ติดตั้ง — 4 ส่วน ประมาณ 45 นาที

### ส่วนที่ 1 · Google Sheet + Apps Script

1. สร้าง Google Sheet เปล่า ตั้งชื่อ `thai-ur checkin`
2. **Extensions → Apps Script**
3. ลบโค้ดตัวอย่างใน `Code.gs` แล้ววางเนื้อหาจาก `Code.gs` ในชุดนี้
4. **+** ข้าง Files → Script → ชื่อ `Setup` → วาง `Setup.gs`
5. เฟือง **Project Settings** → ติ๊ก *Show "appsscript.json" manifest file* → กลับไป Editor → เปิด `appsscript.json` → วางเนื้อหาจากชุดนี้
6. **Deploy → New deployment → ⚙ → Web app**

   | ช่อง | ค่า |
   |---|---|
   | Execute as | **Me** |
   | Who has access | **Anyone** |

   กด Deploy → **คัดลอก URL เก็บไว้** (นี่คือ `API_URL`)

   ครั้งแรกจะขออนุญาตเข้าถึงบัญชี — Advanced → Go to … (unsafe) → Allow ปกติ เพราะเป็นสคริปต์ของคุณเอง

7. กลับไปที่ Sheet → รีเฟรช → เมนู **🕘 เช็กอิน thai-ur → 1. ติดตั้งระบบ**

> "Anyone" ไม่ได้แปลว่าใครก็เข้าถึงข้อมูลได้ — ทุกคำขอต้องแนบ ID token ที่ Google ยืนยันแล้ว และอีเมลต้องอยู่ใน Roster

### ส่วนที่ 2 · Google Cloud — สร้าง OAuth Client ID

1. ไปที่ [console.cloud.google.com](https://console.cloud.google.com) → สร้าง project ใหม่ ชื่อ `thai-ur-checkin`
2. **APIs & Services → OAuth consent screen**
   - User Type: **External** → Create
   - App name: `thai-ur office เช็กอิน` · User support email: อีเมลคุณ · Developer contact: อีเมลคุณ
   - Scopes: ไม่ต้องเพิ่มอะไร กด Save and Continue ผ่านไป
   - Test users: ถ้าปล่อยสถานะเป็น *Testing* ต้องเพิ่มอีเมลพนักงานทุกคนที่นี่ (จำกัด 100 คน) — **หรือกด Publish app** ให้เป็น Production ซึ่งง่ายกว่าและไม่ต้องผ่านการตรวจสอบ เพราะไม่ได้ขอ sensitive scope ใดๆ
3. **APIs & Services → Credentials → + Create Credentials → OAuth client ID**
   - Application type: **Web application**
   - Name: `checkin web`
   - **Authorized JavaScript origins** → ADD URI:
     ```
     https://<ชื่อ-github-ของคุณ>.github.io
     ```
     ใส่แค่โดเมน **ไม่ต้องมี path และไม่มี / ปิดท้าย**
   - Authorized redirect URIs: ไม่ต้องใส่
4. กด Create → **คัดลอก Client ID** (ลงท้าย `.apps.googleusercontent.com`)

### ส่วนที่ 3 · GitHub Pages

1. สร้าง repo ใหม่ชื่อ `thai-ur-checkin` — **ต้องเป็น Public** (แพลนฟรีของ GitHub ให้ Pages เฉพาะ repo public)
2. แก้ `web/config.js` ใส่ค่าที่ได้มา:
   ```js
   window.CHECKIN_CONFIG = {
     GOOGLE_CLIENT_ID: '1234....apps.googleusercontent.com',
     API_URL: 'https://script.google.com/macros/s/AKfy..../exec'
   };
   ```
3. อัปโหลด `index.html` และ `config.js` **ไว้ที่ root ของ repo** (ไม่ต้องมีโฟลเดอร์ web)
   ```bash
   git init
   git add index.html config.js
   git commit -m "ระบบเช็กอิน thai-ur office"
   git branch -M main
   git remote add origin https://github.com/<user>/thai-ur-checkin.git
   git push -u origin main
   ```
4. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**
5. รอ 1–2 นาที ได้ URL `https://<user>.github.io/thai-ur-checkin/` — **นี่คือ `APP_URL`**

> **ไม่อยากให้ repo เป็น public?** ใช้ [Cloudflare Pages](https://pages.cloudflare.com) แทน — ฟรีและต่อกับ private repo ได้ ขั้นตอนเหมือนกัน แค่เปลี่ยน origin ใน Google Cloud เป็นโดเมนของ Cloudflare

### ส่วนที่ 4 · ตั้งค่าและลงทะเบียน

1. ชีต **Config** กรอกช่องสีเหลือง 4 ช่อง:

   | Key | ค่า |
   |---|---|
   | OFFICE_LAT | จาก Google Maps คลิกขวาที่ออฟฟิศ เช่น `13.7563` |
   | OFFICE_LNG | เช่น `100.5018` |
   | GOOGLE_CLIENT_ID | Client ID จากส่วนที่ 2 |
   | APP_URL | URL จากส่วนที่ 3 |

   ปักหมุด**กลางอาคาร** ไม่ใช่ที่ประตู ถ้าตึกใหญ่หรือ GPS ไม่ดี เพิ่ม `RADIUS_M` เป็น 150–200

2. ชีต **Roster** กรอก ชื่อ-สกุล · ตำแหน่ง · **อีเมล Google** ของแต่ละคน (ลบแถวตัวอย่างสีเทาออกก่อน)
3. เมนู **🕘 → 2. ลงทะเบียนอีเมลพนักงาน** — ระบบจะแปลงอีเมลเป็น hash และแทนช่องอีเมลด้วยแบบย่อ `som***@gmail.com`
4. เมนู **🕘 → ทดสอบการตั้งค่า** — ต้องขึ้น ✓ ทุกบรรทัด
5. ส่ง `APP_URL` ให้พนักงานทุกคน — **ลิงก์เดียวกันหมด** บอกให้ Add to Home Screen ไว้

## ชีตต่างๆ เก็บอะไร

**Roster** — รหัส · ชื่อ-สกุล · ตำแหน่ง · สถานะ · อีเมลแบบย่อ · Hash · อุปกรณ์
**Log** — ทุกครั้งที่มีคนกด รวมครั้งที่ถูกปฏิเสธ (ไว้ตรวจย้อนหลัง)
**Daily** — หนึ่งแถวต่อคนต่อวัน: เวลาเข้า · เวลาออก · ชั่วโมงรวม · สถานะ · ธง

**ไม่มีคอลัมน์ไหนเก็บพิกัดของพนักงาน** มีแค่ระยะห่างที่ปัดเป็นหลักสิบเมตร
**ไม่มีคอลัมน์ไหนเก็บอีเมลเต็ม** มีแค่ hash — ถ้าอยากเก็บอีเมลเต็มเพื่อให้ดูแลง่ายขึ้น ตั้ง `STORE_EMAIL` = `TRUE` ในชีต Config แล้วลงทะเบียนใหม่

กฎการบันทึก: วันละ 1 เข้า 1 ออก · เช็กเอาต์ไม่ได้ถ้ายังไม่เช็กอิน · ถ้าอยากให้ออกแล้วกลับเข้าได้ ตั้ง `ALLOW_REOPEN` = `TRUE` (ชั่วโมงรวมจะนับจากเข้าครั้งแรกถึงออกครั้งสุดท้าย)

## ด่านกันโกงที่มี และที่ไม่มี

**มี**

- **ตัวตนยืนยันโดย Google** — ID token ถูกตรวจลายเซ็นที่ `oauth2.googleapis.com` ทุกครั้ง พร้อมตรวจ `aud` (ต้องเป็นแอปเรา) `iss` `exp` และ `email_verified` ปลอมไม่ได้
- ตัดสินระยะที่ฝั่งเซิร์ฟเวอร์เท่านั้น แก้ผ่าน DevTools ไม่ได้
- พิกัดออฟฟิศไม่เคยถูกส่งไปฝั่งเบราว์เซอร์ เปิดดู source ก็ไม่เจอ
- พิกัดต้องสดภายใน 60 วินาที · `accuracy` ต้องดีกว่า 100 ม.
- `LockService` + กันกดรัว 8 วินาที

**ไม่มี — ต้องยอมรับ**

- **GPS ปลอมได้เสมอ** ด้วยแอป Fake GPS หรือ DevTools sensor override — v2 แก้เรื่อง "เป็นใคร" แต่ไม่ได้แก้เรื่อง "อยู่ที่ไหน" ถ้าอยากปิดช่องนี้ ต้องเพิ่มรหัสหมุนเวียนบนจอที่ออฟฟิศ
- ถ้าพนักงานให้รหัส Gmail เพื่อนไปเลย ก็ยังกดแทนได้ (แต่ไม่ค่อยมีใครทำ)

**สรุป: ใช้ดูว่าใครมาไม่มาได้ดี ถ้าจะเอาไปตัดเงินเดือน ควรมีคนตรวจชีตควบคู่ไปด้วย**

## แก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| ปุ่ม Google ไม่ขึ้น | `GOOGLE_CLIENT_ID` ใน config.js ผิด หรือยังไม่ได้ใส่ |
| ขึ้น `origin is not allowed` | Authorized JavaScript origins ใน Google Cloud ไม่ตรงกับ URL จริง — ต้องเป็น `https://<user>.github.io` ไม่มี path ไม่มี `/` ปิดท้าย |
| ล็อกอินได้แต่ขึ้น "ยังไม่ได้ลงทะเบียน" | อีเมลไม่ตรงกับที่ลงทะเบียน หรือลืมกดเมนู *ลงทะเบียนอีเมลพนักงาน* — ถ้ามีหลายบัญชี Google ให้สลับบัญชี |
| ขึ้น "ระบบยังตั้งค่าไม่ครบ" | `GOOGLE_CLIENT_ID` ในชีต Config ว่าง หรือไม่ตรงกับใน config.js |
| ไม่ได้รับอนุญาตให้เข้าถึงตำแหน่ง | เปิดในเบราว์เซอร์ในแอป LINE / Facebook — ต้องเปิดใน Chrome หรือ Safari |
| "เชื่อมต่อเซิร์ฟเวอร์ไม่สำเร็จ" | `API_URL` ผิด หรือลืม Deploy เป็น Web app แบบ Anyone |

หน้าเว็บมีทางสำรอง JSONP ในตัวอยู่แล้ว ถ้า CORS ของ Apps Script มีปัญหา มันจะสลับไปเองอัตโนมัติ

## PDPA — ข้อความแจ้งพนักงาน

ส่งข้อความนี้ให้พนักงานพร้อมลิงก์ (หรือติดประกาศ) เพื่อให้มีหลักฐานการแจ้งตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล

> **ประกาศการเก็บข้อมูลการลงเวลาทำงาน — thai-ur office**
>
> บริษัทใช้ระบบเช็กอินผ่านเว็บเพื่อบันทึกเวลาเข้า-ออกงาน โดยมีรายละเอียดดังนี้
>
> **ข้อมูลที่เก็บ** ชื่อ-สกุล · ตำแหน่ง · อีเมล Google แบบย่อและค่า hash สำหรับยืนยันตัวตน · วันและเวลาที่กดเช็กอิน/เช็กเอาต์ · ระยะห่างโดยประมาณจากที่ตั้งสำนักงาน (ปัดเป็นหลักสิบเมตร) · รหัสอุปกรณ์แบบสุ่มที่ไม่ผูกกับตัวบุคคล
>
> **ข้อมูลที่ไม่เก็บ** พิกัด GPS ของท่าน · ประวัติการเดินทาง · รหัสผ่านบัญชี Google ของท่าน · ข้อมูลใดๆ นอกช่วงเวลาที่ท่านกดปุ่มเอง ระบบจะอ่านตำแหน่งเฉพาะวินาทีที่ท่านกดปุ่มเท่านั้น และส่งกลับมาเพียงว่า "อยู่ในพื้นที่หรือไม่"
>
> **การลงชื่อเข้าใช้** ระบบใช้ Google Sign-In เพื่อยืนยันว่าเป็นตัวท่านจริง บริษัทไม่เห็นรหัสผ่านของท่าน และไม่มีสิทธิ์เข้าถึงอีเมลหรือไฟล์ใดๆ ในบัญชีของท่าน
>
> **วัตถุประสงค์** บันทึกเวลาทำงานและคำนวณชั่วโมงทำงาน
>
> **ระยะเวลาเก็บ** ___ ปี ตามระยะเวลาที่กฎหมายแรงงานกำหนด
>
> **ผู้เข้าถึงข้อมูล** ฝ่ายบุคคลและผู้บริหารที่เกี่ยวข้อง
>
> **สิทธิของท่าน** ขอดู ขอแก้ไข หรือขอให้ลบข้อมูลของท่านได้ ติดต่อ ___
>
> หากท่านไม่สะดวกใช้ระบบนี้ (เช่น ไม่มีสมาร์ตโฟน) โปรดแจ้งฝ่ายบุคคลเพื่อใช้วิธีลงเวลาแบบอื่น

ช่องว่างให้เติมเอง: ระยะเวลาเก็บข้อมูล และผู้ติดต่อ
